Week 2026-W46

Management summary

  • Copilot and Copilot Chat grounding is being tightened with a Purview DLP control to exclude external/untrusted email content while keeping trusted internal Microsoft 365 sources (MC1301714).
  • Workforce Insights data ingestion is changing: the MODS Workforce Insights endpoint is retiring by Nov 18, 2026, and custom organizational data must move to the Microsoft 365 profile endpoint via a private preview to avoid stale data/uploads failing (MC1542066).
  • Copilot Cowork is expanding Power Platform connector governance: connectors can follow Microsoft 365 admin center allow/block controls, but Power Platform admin center DLP policies do not apply to Cowork (MC1542062).
  • Dynamics 365 Project Operations roadmap items include deprecating “transaction origins” (high relevance) plus multiple invoice/budget usability and commitment-related enhancements (547c0709, 9d2061de, cd421486, f85fe6a9).
  • Dynamics 365 Contact Center is adding/expanding AI-driven conversation orchestration (natural-language playbooks and bullseye routing with user groups) and role-based enforcement for recording/transcript downloads (86011dc6, 5e77f9e2, 67f7a4b4, 1355095c).
  • Power Platform and Power Apps Copilot-related features are seeing support/feature lifecycle changes (Power Automate Copilot in designer end of support Nov 30, 2026; AI-generated descriptions for model-driven apps end of support Nov 30, 2026) (1355095c, 7568d30b, f3c2992b).
  • Several Microsoft 365 admin and governance changes may affect delivery and compliance workflows (e.g., Exchange Online Admin API permission updates and MailboxFolderPermission response shape change) (52fb9a91, ba7cf8fb).

Calls to action

  • Assess Copilot grounding and email governance impact — Purview DLP will be able to exclude external/untrusted email content from Copilot and Copilot Chat grounding while leaving delivery/retention/eDiscovery/access unchanged; confirm how this affects your customer scenarios and data sources (MC1301714).
  • Plan MODS endpoint migration for Workforce Insights custom attributes — The MODS Workforce Insights endpoint is retiring by Nov 18, 2026; organizations using custom non-public attributes must join the private preview and explicitly switch endpoint selection to avoid stale data and failed uploads (MC1542066).
  • Review Copilot Cowork connector governance and DLP expectations — Power Platform connectors in Copilot Cowork will follow Microsoft 365 admin center allow/block settings, but Power Platform admin center DLP policies do not apply to Cowork—validate governance/compliance alignment for connector-enabled integrations (MC1542062).
  • Validate Dynamics 365 Project Operations roadmap implications for billing and transaction behavior — Roadmap items include deprecating “transaction origins” (high relevance) and invoice/budget enhancements (invoice limits, invoice usability, cost commitments), which may affect existing implementations and process design (547c0709, 9d2061de, cd421486, f85fe6a9).
  • Update integration and admin automation for Exchange Online Admin API changes — Exchange Online Admin API v2.0 permissions are changing by Nov 2026, and the MailboxFolderPermission endpoint’s User property changes from a display-name string to a structured object—update apps/third-party solutions to prevent access and parsing errors (MC1540345, MC1540342).
